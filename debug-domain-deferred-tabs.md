# [OPEN] debug-domain-deferred-tabs

## Симптом
На домене после переключения на вкладки EDA / SQL / ML UI показывает "Помилка завантаження", хотя локально и серверные `/ui/*` эндпоинты могут отвечать корректно.

## Гипотезы
1. Deferred fetch на домене получает не HTML partial, а другой ответ из-за proxy/base URL/redirect.
2. Клиентский JS падает после успешного fetch при парсинге или замене DOM.
3. После `replaceWith` ломается повторный поиск экранов/активация вкладки и UI уходит в error state.
4. На домене запросы к `/ui/*` блокируются или модифицируются reverse proxy/CSP/headers.
5. Вкладки грузятся успешно, но следующий JS шаг кидает исключение, которое попадает в общий catch и рисует ошибку.

## План
- Добавить клиентскую instrumentation-диагностику для deferred tabs.
- Собрать runtime evidence на домене.
- Подтвердить корневую причину.
- Внести минимальный фикс.
- Проверить до/после.
