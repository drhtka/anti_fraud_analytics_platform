End-to-End Anti-Fraud MVP

Антифрод-скоринг транзакцій

Цей MVP показує повний anti-fraud workflow: від EDA та SQL-інсайтів до ML-скорингу й пояснюваного рішення для конкретної транзакції. На одному екрані зібрані fraud score, активні сигнали ризику, рішення щодо manual review та технічний API-вивід для перевірки інтеграції.

EDA та SQL

Пошук fraud-патернів у транзакціях і живі зрізи з локальних даних.

ML scoring

Оцінка ризику, активні сигнали та рішення щодо manual review.

API + UI

Пояснюваний результат для демо, Swagger і перевірки інтеграції.
